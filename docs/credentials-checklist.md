# Credentials checklist · what activates each connection

One list of what you need to do to activate and verify every connection, after `connect-tools`, `ux-round` and `int-round` are released. Nothing here goes into the code or the chat: every key is pasted into **Connection** in the studio (stored encrypted in the settings table) or granted inside the provider's own console. Never paste a key into a chat message.

"Verify" names the check the studio itself runs when you save; a connection is complete only when that check passes and the first real operation worked.

## The order that makes sense

1. Release `int-round` to production (migrations 0068–0072 are additive) once you have looked at the preview.
2. Enter the video estimate (item 1) and make one clip (item 2): this is the first live verification of Higgsfield in the studio.
3. Freepik key and plan (items 3, 4); then a search, one download and one Photo lab run on a demo-safe picture.
4. Instagram publishing token (item 7) when you want to publish from the studio; Drive Outputs folders (item 8) when you want deliveries.
5. The optional ones (5, 6, 10, 11) when needed.
